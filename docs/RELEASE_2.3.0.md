# 众行无限画布 2.3.0

经项目负责人确认，从已验收的 2.3.0-local.2 发布。更新保留原图、画布、项目文件、任务与自定义规则，不改变用户数据目录。

## 本次更新

- 五类默认审美规则升级完整 V2；只更新未改写的默认内容，手动修改、上传、改名和删除记录保留。
- 新增五种可编辑质感预设：真人、社媒、三维、产品静物、KV 标题字。可清空描述变量，叠加所选审美规则；标题字使用插件自带的单张流程。
- 点击开始生图立即关闭弹窗，画布显示正在提交的占位框；发送失败重发同一任务，创建失败可恢复原输入，避免重复点击与永久禁用。
- 图片操作新增生图参数。本版从生图弹窗创建的新图可复用最终提示词、比例、预设、规则与参考图；刷新和项目导入导出后保留。缺少完整记录的旧图明确提示，不猜测参数。
- 默认高清处理提供独立线程的本地保真放大，不消耗生图额度；保留 AI 整图修复选项。
- 页面级异常进入明确恢复界面，尝试保存最新内存快照再重新加载；移动相关更新合并，项目保存串行处理，防止旧状态覆盖新状态。

## 验证与限制

73 项自动测试通过，完成类型/构建检查、371 个发布文件检查、22 工具握手、隔离干净安装、升级数据保留和真实 Codex App Server 加载测试。MCP App 界面完成三种变量填写方式、老图/新图参数、刷新恢复、参考图复用、创建失败恢复及重复提交保护回归。

界面出图回归使用固定 PNG 模拟模型回填，不代表真实生成质量验收。模型可用性与额度取决于用户账号。本地保真放大是轻度去噪与插值，不是学习型超分，可能偏软或保留已有强噪纹；AI 修复仍可能改变细节。页面不能捕获宿主整个渲染进程退出，未保存操作仍有丢失风险，不能承诺根治灰屏。生图参数记录暂针对生图弹窗创建的图片，不伪造历史图片修改/高清任务的完整参数。

## 安装或更新

首次安装：

```bash
codex plugin marketplace add fangwen950718-lvlv/zhongxing-canvas --ref main
codex plugin add zhongxing-canvas@zhongxing-canvas-github
```

已有正式版：先导出项目备份，再更新 Marketplace；仅在更新成功后重新安装插件。

```bash
codex plugin marketplace upgrade zhongxing-canvas-github
codex plugin remove zhongxing-canvas@zhongxing-canvas-github
codex plugin add zhongxing-canvas@zhongxing-canvas-github
```

下载失败时保留原安装，不要先移除。完成后完全退出并重新打开 Codex，新建对话发送“打开众行无限画布”，确认显示 V2.3.0。无需 npm ci、开发工程或 Vite。系统要求与用户数据备份位置见 README。
