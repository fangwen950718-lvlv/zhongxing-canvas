# 众行无限画布 2.2.0

基于已验收的本机测试版发布，保留原图、批注、项目和用户自定义规则。

## 本轮更新

- 新导入和生成图片按实际像素尺寸放置；选中图片显示原图与画布尺寸，已有手动缩放不变。
- 智能高清 ×2/×4 使用完整画面 AI 修复，再统一输出尺寸；结构稿抑制细碎噪点与蚯蚓纹，结果放在原图旁。
- 项目导出显示保存与写入阶段，直接保存到下载目录并返回路径、大小；重名不覆盖，浏览器后备提供保存链接。
- 减少拖动缩放时图片重复序列化、合并连续操作的自动保存，顺序校验图片并释放临时解码引用。
- 人物海报默认规则升级为真实商业摄影、自然肤质、明确棚拍布光和简洁场景。手动编辑过的规则不覆盖；请重新生成方案应用新版规则。
- 移除底部装饰线与顶部 PNG/SVG 入口；帮助按钮放到左下角缩放上方，单图下载保留。

## 已知边界

- 智能高清最后一步为 Lanczos-3 重采样，不是模型原生目标分辨率或专用超分；AI 可能改变文字与细节，不保证恢复丢失信息。最大边 8192px、总像素 3200 万。
- 灰屏的宿主渲染进程崩溃根因尚未确认。本轮降低已知开销，不宣称已根治；见 docs/STABILITY_DIAGNOSIS.md。
- 项目导入与保存上限 100MB，超过请拆分项目。导出包含当前画布及保留的结果，不含完整 Codex 对话；完整档案需备份用户数据目录。

## 发布验证

- 61 项自动测试通过，包含原图下载、尺寸与透明校验、高清处理、规则迁移、导出与保存调度。
- 类型检查、开发构建、插件构建、版本一致性与隐私路径扫描通过；入口 111,830 字节，资源分块门禁保留。
- 隔离发布包启动、项目保存恢复、损坏输入保护、任务建立与换安装目录后数据保留通过。
- 隔离 CODEX_HOME 的真实 Codex App Server 安装并识别 22 个工具；旧配置错误复现测试通过。
- 本轮为已验收功能的版本整理，不另耗生图额度；此前真实生图与模拟回填的区分详见 docs/LOCAL_TESTING.md。灰屏不算已根治。

## 更新步骤

先备份项目，运行 `codex plugin marketplace upgrade zhongxing-canvas-github`。成功后运行：

```bash
codex plugin remove zhongxing-canvas@zhongxing-canvas-github
codex plugin add zhongxing-canvas@zhongxing-canvas-github
```

下载失败先保留现有安装。更新后完全退出并重新打开 Codex，新建对话发送“打开众行无限画布”。
