## 本次变更

选中图片后在附近显示修改标注、下载原图、延展尺寸、去除背景。下载由 MCP 将原始字节保存到“下载”文件夹，重名自动编号；延展和 AI 去背沿用当前对话任务链路，结果保留原图并寻找空位回填。界面统一为中性灰，Logo 与画布内容不改色。

延展需要核对 AI 输出的文字和细节；去背首版面向干净背景。模型不保证逐像素保真，也不保证复杂发丝边缘质量。延展仍检查目标比例；去背接受不同尺寸、比例，仅拒绝白底假透明、全透明空图和重复完成。选中图片操作条置于图片上方，标注和原图自动成组，旧标注载入时也会补组。

- local.3 的 39 项测试、类型检查、发布包检查、隔离安装及真实 Codex 加载器通过。SDK 宿主实测统一规则列表、改名/全文编辑、删除确认、上传新文件及保存；规则导入导出与删除不复活另有自动测试。

- 打开工具声明官方 openai/ui global/thread entrypoints，探针验证返回元数据；原生左侧菜单出现、固定与头像缓存刷新仍需重启客户端验收，不能视为已验证支持。

## 本机试用

完全退出并重新打开 Codex，新建对话，选择众行无限画布本机版，发送“打开众行无限画布”。应显示 `V2.1.0-local.4`。测试时不要运行 GitHub 安装或升级命令。

默认用户数据位置保持不变。项目仍为 format `zhongxing-canvas`、version `1`；新任务类型是增量扩展。

## 回退

由维护者在项目目录执行：

```bash
node scripts/local-install.mjs --rollback
```

随后完全退出并重开 Codex。此操作只停用本机版、恢复正式版原启用状态，不删除项目，也不覆盖当前用户配置中的其他设置。

安装状态与首份备份位置保存在 `verification/local-2.1/install-state.json`。除非明确要求恢复项目，不要用旧备份覆盖用户后续试用产生的画布。
