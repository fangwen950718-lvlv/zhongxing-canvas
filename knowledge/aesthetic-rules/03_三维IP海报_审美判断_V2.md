# 三维IP海报审美判断 V2

用途：供众行无限画布生成三维品牌IP海报方案与完整 demo 提示词。先守住形象识别，再用角色行为、场景和图文组织产生创意。版本日期：2026-10-26。


## 导入与使用说明

用本文件完整替换对应分类的旧正文，不把V1与V2叠加；若上传后新增了规则库，需要选择该V2规则库才会生效。只替换分类正文不会自动更改通用底层规则，文中的兼容建议需在通用规则编辑区同步处理。兼容检查依据已安装插件2.2.0-local.5的默认通用规则，不代表已读取各项目自行保存的规则快照。

正文是执行规则，示例和文末案例是理解材料。实际任务只使用当前brief及其真实附件；不得把示例品牌、文案、角色、尺寸、场景或案例中的事实带入客户项目，也不要求每次复用示例的三种风格。文末参考不属于成图文字，不应全部塞进每次方案或提示词。

## 1. 适用范围与约束来源

适用于品牌吉祥物、三维角色、潮玩或联名IP的海报表现。只执行本类别与 brief 明确提出的业务要求，不自动加载社媒、产品或资源位规则。促销利益、产品露出、联名顺序和行动信息只有 brief 确认后才加入。

IP规范与已确认素材是造型依据。先区分：不可改的识别特征、允许变化的表情动作、可增加的场景服饰道具。没有明确许可时，不改头身比例、耳朵形状、眼距、嘴鼻位置、标志配色与身体结构，不把“可爱一点”理解为大眼、圆脸、短腿重设计。

参考图必须实际附入生成任务。只有一张正面图时，不推断完整背部结构；优先用已知视角设计动作与构图。需要全新侧背面且缺乏规范时，明确该视角待确认，不能声称严格符合品牌标准。没有IP素材时可提出构图方向，但不能把熟悉品牌角色或原创替代角色冒充客户IP。

恰好输出三组 options，每组有简短 title、1—2句 proposal、4—8组 label/content sections 和独立完整的中文 imagePrompt。sections 组织为IP锁定项、角色行为、场景、构图、文字、色光材质及风险，不强制每组都有前中后景。默认包含实际标题和品牌信息的完整海报；确定文案不得擅改，建议文案需明确标注。无Logo素材时只用确认的品牌文字署名。

## 2. 案例规律：角色稳定，世界可变

- 美团相关样本中，同一识别形象可以进入咖啡店、海滩、理发店和露营场景。变化主要发生在行为、环境和活动语境，角色轮廓及五官关系仍能识别。不能把场景自由误写为角色造型自由。
- 三维场景的有效复杂度取决于叙事。角色坐在理发椅上，椅子、镜面与店内灯光解释行为；多加无关气球和金币不会提高完成度。
- 一套IP可以使用不同材质表现，但材质变化需要规范支持。绒毛近景、光滑玩偶和塑料潮玩不是可以任意互换的通用皮肤。
- 场景的透视、道路、建筑与台座常用于把视线带向角色。低机位可以有气势，但过度广角会把头、耳朵和身体比例拉偏，必须优先保护识别。
- 图文通常分工明确：标题交代活动，角色演示一个行为，底部模块收纳次要信息。标题可以是第一阅读入口，不能机械要求角色永远压过所有文案。
- 联名样本通过场景、道具、服饰或色彩表达合作关系，不必把两方Logo无限放大；改变角色服装仍需许可，不能复制参考中其他品牌的合作事实。

IP画板也混有实拍玩具、二维插画和普通物料。只把具备三维体积、材质和空间关系的案例用于三维判断；实拍玩具可以借鉴光线与陈列，不能据此确认其为CG制作。

## 3. 决策顺序与创意方法

1. 建立“IP锁定卡”：整体轮廓、头身关系、耳角尾等突出结构、五官形状位置、主配色、标志图案、四肢结构、基础材质。只写有来源支持的特征；不编造精确比例。
2. 确认 brief 的一句主题和角色任务：角色是在等待、递出、探索、庆祝还是陪伴。每个画面只围绕一个主要行为展开。
3. 选择支持行为的场景。咖啡主题可以是取杯窗口、杯口空间或晨间桌面，不能只因为“好看”把不相干的宇宙、海滩和古建筑拼在一起。
4. 决定角色尺度与相机关系，再决定标题组。角色是巨物时，环境必须给出可读的尺度参照；角色是桌面玩偶时，接触阴影与道具尺寸必须相容。
5. 设计一个视觉转折：日常场景的尺度反差、物件功能的转化、角色间的明确互动，任选符合主题的一种。转折不能通过拉长身体、换脸或改头型实现。
6. 最后统一材质、光向与配色。三组差异从场景机制、叙事视角或构图关系产生，而非只换三种节日装饰。

创意检验：拿掉IP后若画面仍是任意品牌都能用的背景，补足角色与事件的联系；拿掉多余道具后故事更清楚，就删掉道具。IP不是放在漂亮布景里的标志物，它应当参与一个可见事件。

## 4. 构图、空间与图文规则

| 场景条件 | 具体动作 | 判断标准 |
|---|---|---|
| 单角色、单活动 | 用一处舞台、桌面或场景核心承载角色；标题放连续色面 | 角色、事件、主题之间有最短阅读路径 |
| 微缩店铺或城市 | 用门窗、道路、柜台构成导视，降低远处细节，角色附近保留呼吸空间 | 不是建筑模型比IP更醒目 |
| 巨物IP | 保持角色原比例，以真实尺度的小物或环境作对照，控制透视夸张 | 体量来自参照而非身体变形 |
| 多IP或多人联名 | 明确主次与每个角色的参考对应，行为有来有往 | 不串脸、混色、复制肢体，Logo顺序符合brief |
| 信息多、促销明确 | 将利益点、说明与行动区归为稳定信息模块，给主画面保留完整行为 | 文字可读，IP不被底部模块截去关键特征 |
| 近景材质展示 | 保留完整识别轮廓或足够五官特征，降低背景细节 | 近看有质感，缩小仍认得角色 |

不得用道具遮住最有识别度的耳朵、头顶、眼睛或胸前标志。可自然遮挡非关键部位，但提示词要交代前后次序。动作尽量以角色原有骨架完成；短手臂角色不要被强迫做真人般复杂交叉手势。

头顶、耳尖与标题之间避免似碰非碰。要么保留明确距离，要么有意重叠且字与特征仍完整；不能让一笔标题看起来像长在头上的新结构。画面外框也不能压扁角色。

标题按语义断行，以清晰的中文字体为基础；三维字仅在风格需要时使用，字的厚度、透视和反射不能妨碍识读。正文、活动条件和品牌信息用稳定平面文字，与三维舞台建立清晰分层，不把所有小字做成漂浮立体字。

## 5. 材质、灯光与形象保持

### 形象锁定

- 轮廓先于细节：转角、耳长、头宽、身体比例与附件数量先检查，再看贴图与高光。
- 五官按规范：眼睛大小、间距、朝向与高光不能随情绪随意变；没有表情规范时，优先保持参考表情，用动作和场景表达情绪。
- 配色按规范：背景光可以影响局部阴影，但不能把角色标志色变成别的品牌色。强烈彩光下仍需保留可识别的主色。
- 材质按规范：原角色是哑光光滑表面时，不能为了“高级”改成金属、毛绒或玻璃；服饰和道具可单独定义材质。
- 联名按素材：不能把一个角色的眼睛、耳朵和服装拼到另一个角色上，也不能从已有品牌案例推导本次合作许可。

### 三维质感

先定义角色、服装、场景主体的材质差异，再给出统一灯光。材质可以多样，但每种都应有用途；不要把“金属、玻璃、毛绒、糖果、陶瓷”一口气堆到单一角色上。

光滑哑光表面需要宽而柔的高光与合理渐变；毛绒需要可辨绒毛方向但不能糊掉五官；金属需有环境反射但不照出无关空间。所有材质都需要统一接触阴影、反射方向与光源关系。

前景、角色与背景的清晰度按任务分配，不能用过浅景深模糊IP脸部或关键信息。曝光控制尤其检查黄色、白色和黑色角色：黄色不溢成白块，白色不消失在背景，黑色五官不融为一片。

## 6. 提示词结构与限制

写明：已附IP参考的锁定特征；画幅与用途；角色行为与关键接触；角色位置、视角和尺度；场景结构；材质及光源；全部实际文字的原文、断行、位置；品牌标识使用；具体风险。

“C4D质感”“精致渲染”不能代替材质和光的描述；不规定必须使用某款软件。默认选择能显示关键五官与轮廓的视角，除非 brief 另有要求。提示词不杜撰标准三视图，也不将参考网页地址当成实际图像附件。

生成后要按锁定卡逐项核对，不通过时优先局部修正或复用确认IP素材，再调整环境；不能以一次新生成“看着像”替代形象规范验收。文字与Logo同样需人工核对，完整海报不等于可以承诺所有汉字自动准确。

## 7. 三组完整示例

虚构 brief：品牌“慢岛”周末陪伴海报，3:4；确定标题“周末，慢一点。”，署名“慢岛”。示例假定已附经确认的虚构IP“团团”规范图：奶油白圆头、两只短圆耳、黑色豆形眼、无鼻、固定小弧线嘴、短四肢、头身关系以参考图为准；左胸一枚蓝色圆点标记；基础材质为光滑哑光；允许改变四肢动作，五官与表情不变。不增加活动利益或日期。

### OP1｜把清晨坐慢

**proposal：** 团团坐在一张真实尺度的窗边椅上看向晨光，用一个安静动作表现周末陪伴。

**sections：**
- IP锁定：轮廓、耳朵、眼嘴、蓝色胸点及哑光材质按规范保持。
- 行为：坐姿，双脚自然垂落，双手搭在椅面；不增加手持物。
- 场景：窗、椅与少量地面构成真实安静空间。
- 构图：角色右下，左上墙面承字，耳尖完整可见。
- 色光：奶油白、浅木色与低饱和天蓝，柔和侧光。
- 文字：两行主标题和底部署名，不做立体字。

**imagePrompt：** 根据实际附入的“团团”IP规范图生成3:4竖版完整三维品牌海报。严格保留奶油白圆头、两只短圆耳、黑色豆形眼、无鼻、固定小弧线嘴、短四肢、原头身比例和左胸蓝色圆点，基础表面保持光滑哑光，不改成毛绒。角色位于右下，坐在浅木色窗边椅上，双手自然搭在椅面，短脚自然垂落，脸与耳朵完整可见，胸点不遮挡。场景仅保留左侧窗、椅和浅米色墙面地面，晨光按单一方向照入，角色与椅面有真实接触阴影。左上深蓝清晰中文中黑体排两行“周末，”／“慢一点。”，左下小字“慢岛”。标题不压耳朵，只有指定文字，不加日期、价格或图形Logo。保留原五官与表情，不新增鼻子、手指、装饰耳朵和背景杂物。

### OP2｜一叶小舟的周末

**proposal：** 让团团乘一片放大的叶子缓慢漂行，借尺度转化表现轻松，不改变角色本身比例。

**sections：**
- IP锁定：与OP1保持同一模型、五官、标记与材质。
- 行为：坐在叶片中央，手扶叶缘，胸点朝向镜头。
- 场景：一片叶子与平静浅水，涟漪说明支撑关系。
- 构图：叶片由左下向右中形成路径，角色位于中下。
- 色光：浅蓝水面、低饱和绿叶，光线柔和，白色轮廓可辨。
- 文字：上部稳定区域排标题，署名在右下。

**imagePrompt：** 生成3:4竖版完整三维IP海报，使用已附团团规范图，保持奶油白圆头、双短圆耳、黑色豆形眼、无鼻与固定弧线嘴、短四肢、参考头身比例、左胸蓝点及光滑哑光材质。角色坐在一片放大的浅绿色叶片中央，双手轻扶叶缘，胸前标记与双耳无遮挡；角色比例不变，尺度奇趣只来自大叶片。叶片由左下向右中延伸，浮在平静浅蓝水面，叶下接触、水面涟漪和轻倒影说明支撑，不让角色直接悬浮。镜头为温和略俯视，避免广角拉伸。上部低细节浅色水面用深蓝中黑体写两行“周末，”／“慢一点。”，右下小字“慢岛”。文字清晰平直，不做水面倒字或三维字。不要加鱼群、花海、金币或其他角色；不改眼距、不新增鼻子、不把叶缘与手臂融合。

### OP3｜把忙碌关在门外

**proposal：** 用一个抽屉式微缩房间表现周末的私人空间，让团团成为空间里的明确主角。

**sections：**
- IP锁定：保持同一规范造型，站姿可变，表情不变。
- 场景：单个打开的抽屉变成微型客厅，不再混合叶舟或窗边晨光叙事。
- 行为：团团站在抽屉中央，一手扶门形边框，脚有支撑。
- 构图：微缩空间占中下部，上部文字主导，低对比室内物件退后。
- 色光：浅木色外框、柔蓝内墙、奶油白角色，同一柔光。
- 文字：标题两行居中，底部署名居中，与抽屉中轴相合。

**imagePrompt：** 制作3:4竖版完整三维品牌IP海报，严格按已附团团规范图保留圆头、双短圆耳、豆形黑眼、无鼻、固定弧线嘴、短四肢、头身比例、奶油白主色、左胸蓝色圆点与光滑哑光表面。中下部是一只打开的浅木色抽屉，内部变成柔蓝色微型房间，仅有一张小地毯和一个简洁坐垫。团团站在抽屉中央，一手轻扶门形边框，胸点朝向镜头，双脚确实站在底板上；边框不挡头耳。略俯视但保留正面识别，统一柔光，室内物件低对比退后。上部浅色背景居中排两行深蓝标题“周末，”／“慢一点。”，底部居中署名“慢岛”。标题平直清晰，除指定文案外不加门牌、时间、活动价格和Logo图案。不拉长角色，不加毛发、新五官、额外肢体或复杂装饰。

## 8. 反例修正与验收

| 失败表现 | 修正动作 | 验收依据 |
|---|---|---|
| 可爱但不像原IP | 按锁定卡恢复轮廓、比例与五官，再检查配色 | 与确认参考图逐项对照 |
| 穿搭遮住关键标记 | 改道具位置、简化服装，保留识别窗口 | 主要识别特征在成图中可见 |
| 角色悬浮、穿透椅子 | 明确接触点、受力与遮挡，减少复杂互动 | 脚、臀、手及道具接触可信 |
| 角色变成金属或毛绒 | 恢复规范材质，把材质变化转移给环境 | 角色表面与规范一致 |
| 景比角色更抢眼 | 降低远景对比、压缩道具数量、突出轮廓 | 缩略图能识别IP与主要事件 |
| 字被立体效果吞掉 | 降低厚度与透视，改成平面信息层 | 标题和利益点读得出 |
| 三组像同一布景换节日 | 重做行为、尺度或场景机制之一 | 三组各自有一句可辨的事件描述 |

造型识别错误、角色混合、标记错位或缺失、明显肢体穿透属于否决项。文本阶段只能检查提示词约束是否齐全；未实际生成时不得宣称形象已符合规范。

## 9. 通用规则兼容说明

保留单母体、统一世界观和有组织的拼贴。通用规则“表达体验优先使用人的动作和场景行为”建议同步改成“通过主体允许的动作、互动与场景表达体验；IP动作服从其结构与规范”，避免把真人关节逻辑硬套短肢IP。

通用规则把信息固定在第三层，可能削弱活动标题；建议改为“按本任务决定第一阅读入口，再安排主体、动作与信息的层级”。“结构→主体→场景→层级→元素→文案”建议改为“锁定IP与确定文案，先共排主体和文字，再完善场景与质感”。接口仍为恰好三组及独立完整 imagePrompt；不修改插件代码或用户当前快照。
